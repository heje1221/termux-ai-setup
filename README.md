# termux-ai-setup

Install AI CLI tools (OpenCode + MiMoCode) sa Termux.

## Usage

\`\`\`bash
bash install-ai-cli.sh --all
\`\`\`

Interactive menu: run with no arguments.

| Option | Gawain |
|--------|--------|
| `--all` | deps + opencode + mimo |
| `--opencode` | opencode lang |
| `--mimo` | mimo lang |
| `--deps` | dependencies lang |
